# HackcoTasks - بناء وتثبيت ملف الـ APK لنظام أندرويد (Android APK)

هذا الدليل يوضح لك الطرق السريعة لتحويل تطبيق **HackcoTasks** إلى تطبيق أندرويد محلي بالكامل وتثبيته كملف `.apk` على هاتفك:

---

## الطريقة 1: التجميع الآلي الفوري عبر GitHub Actions (بدون تثبيت أي برامج على حاسوبك)

تم إعداد ملف العمل التلقائي جاهزاً داخل المشروع في المسار:
`.github/workflows/build-apk.yml`

### الخطوات:
1. من القائمة العلوية في **Google AI Studio** أو بيئة العمل، اضغط على زر **Settings** ثم اختر **Export to GitHub**.
2. توجّه إلى مستودعك على GitHub، وافتح تبويب **Actions**.
3. ستجد سير العمل **Build HackcoTasks Android APK** يعمل تلقائياً بمجرد إرسال الكود.
4. بمجرد انتهاء البناء (يستغرق حوالي دقيقتين)، اضغط على التشغيل وستجد ملف:
   **`HackcoTasks-Android-APK`** جاهزاً للتنزيل بصيغة `.apk` مباشرة إلى هاتفك!

---

## الطريقة 2: البناء المباشر عبر Android Studio على جهاز الكمبيوتر

1. افتح برنامج **Android Studio** على حاسوبك (Windows / Mac / Linux).
2. اختر **Open Project** واختر مجلد `android` الموجود داخل المشروع.
3. انتظر حتى ينتهي Gradle من المزامنة (Sync).
4. من القائمة العلوية لـ Android Studio اختر:
   `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`
5. سيظهر لك إشعار في الزاوية السفلية يفيد بإنشاء ملف الـ APK:
   `android/app/build/outputs/apk/debug/app-debug.apk`
6. انقل هذا الملف إلى هاتفك عبر البلوتوث، أو Google Drive، أو كابل USB، وثبته فوراً!

---

## الطريقة 3: البناء الفوري عبر سطر الأوامر (Terminal)

إذا كان لديك Java JDK مثبت، افتح سطر الأوامر في مجلد المشروع ونفذ:

```bash
# بناء ملفات الويب أولاً
npm run build

# مزامنة الملفات مع مجلد أندرويد
npx cap sync android

# الانتقال لمجلد أندرويد وبناء الـ APK
cd android
./gradlew assembleDebug
```

الملف الناتج سيكون في:
`android/app/build/outputs/apk/debug/app-debug.apk`

---

## الطريقة 4: التثبيت الفوري كـ تطبيق أندرويد محلي (PWA / WebAPK)

إذا كنت ترغب بتثبيته فوراً على الهاتف بدون جهاز كمبيوتر:
1. افتح رابط التطبيق في متصفح Chrome على هاتف أندرويد:
   `https://ais-pre-y4psubzv42kizwjwkcafmn-372565011480.europe-west2.run.app`
2. اضغط على خيارات المتصفح (الثلاث نقاط) واختر **"تثبيت التطبيق" (Install App)** أو **"إضافة إلى الشاشة الرئيسية"**.
3. سيقوم نظام أندرويد تلقائياً بإنشاء حزمة WebAPK وتثبيتها كتطبيق مستقل تماماً على شاشتك الرئيسية، يعمل محلياً وبدون إنترنت.
